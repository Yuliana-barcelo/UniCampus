# Persona 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Implementar DTOs y guardado validado sin SQL ni cambios en componentes ajenos.
**Architecture:** Entities contiene DTOs e IActividadRepository. BLL consume ese contrato mediante inyección; DAL podrá implementarlo sin referencias circulares. Las modalidades, estados y modalidades con lugar obligatorio se configuran explícitamente.
**Tech Stack:** .NET Framework 4.8, C#, MSBuild Visual Studio 18, MSTest 2.2.10.
**Spec:** Solicitud de implementación Persona 2 del usuario, resumida en docs/persona2-contratos.md.
**Execution:** Autorizada en la solicitud: implementación completa, commit, push y PR hacia master, sin merge. Reutilizar la copia local y la rama solicitadas.

## Global Constraints
- Conservar .NET Framework 4.8 y namespace uniCampus.BLL.
- No SQL, cambios de base de datos, repositories concretos, presenters ni controles.
- No modificar las referencias Web -> DAL/Tests.
- No fijar estados, modalidades ni transiciones sin acuerdo.
- Guardar devuelve identificador positivo o errores seguros; cero llamadas con entrada inválida y una con entrada válida.

## Review Focus
- Horas negativas o de 24 horas: rechazar antes de combinar con fecha.
- Fecha máxima y medianoche: no provocar desbordamiento.
- Catálogos de configuración vacíos o incoherentes: rechazar al construir.
- Error o identificador no positivo de persistencia: no aparentar éxito ni filtrar detalles.
- Fechas con componente de hora: usar Date para combinar con HoraInicio/HoraFin.
